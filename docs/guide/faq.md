## 特殊弹窗：智能应用控制已阻止此应用

![报错弹窗](/images/blocked1.png)

如果你的电脑弹出标题为 **“智能应用控制已阻止此应用”** 的窗口，并写明已阻止 `C:\Program Files\学习通刷课\start.exe`，说明是 Windows 11 的 **智能应用控制（Smart App Control）** 拦截了脚本。

这不是病毒，也不是脚本损坏，按下面的步骤关闭该功能即可。

先打开 **Windows 安全中心**（在开始菜单搜索“Windows 安全中心”就能找到），然后：

<div class="x-steps">

1. 点击 **应用和浏览器控制**。
2. 点击 **智能应用控制设置**。
3. 如果状态是 **“开启”** 或 **“评估中”**，请将其切换为 **“关闭”**。
4. **重启电脑**后再次运行程序。

</div>

::: tip 状态本来就是“关闭”？
那说明拦截不是它造成的，请回到上面的 **方法一 ~ 方法四** 继续排查。
:::

::: warning 关闭前请知悉
智能应用控制一旦关闭，**无法再手动重新开启**（只有重装系统才能恢复）。如果你只是偶尔使用，可以先尝试上面的通用方法，确认确实是它拦截后再关闭。
:::

## 方法一：用管理员权限运行

关闭脚本窗口，然后鼠标右键 `start` 程序，用**管理员权限运行**。

如果出现防火墙提示请先关闭防火墙，然后重新打开脚本。

## 方法二：重新安装

把已经安装的先删除干净，然后再重新下载脚本。

::: warning 注意
删除时请确认脚本目录已清空，避免旧配置残留导致新版本依然报错。
:::

## 方法三：重启电脑

重启电脑后再试一次。
