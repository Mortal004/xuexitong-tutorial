## 省流版

如果不想看长文，按下面三步走即可跑起来：

<div class="x-steps">

- **启动程序**：双击 `Start` 运行，仔细阅读弹出的用户须知，然后进入设置页面。
- **填写并保存**：填写账号密码与课程名称，按需选择功能选项，最后**务必点击“保存”**。
- **开始刷课**：返回“主页”，点击“开始刷课”，脚本会自动打开浏览器登录你的学习通并开始运行。

</div>

有疑问的话，继续往下看详细介绍。

## 1. 启动程序

双击 `Start` 运行。运行后会出现一个弹窗，请仔细阅读用户须知，然后进入到设置页面填写相关信息。

## 2. 配置设置

<div class="x-figure">
  <figcaption>设置页面总览</figcaption>
  <img src="/images/settings.png" alt="设置页面" />
</div>

设置页面中的第一项为**配置设置**，已经填充好了内容，不用修改。

但如果在开始刷课后有提示浏览器相关的报错，就需要修改，具体操作见 [如何安装正确的驱动](./driver)。

::: tip 小提示
选择 **Edge** 浏览器后驱动地址会自动填充，是最省事的选择。报错了再去看驱动安装那一章。
:::

## 3. 界面设置

第二项为**界面设置**，可根据个人喜好自行调整。

## 4. 账号信息

第三项为**账号信息**，需要注意三点：

- 需要将你登录学习通的账号密码填写到输入框中；
- 然后填写要刷课的名称，**可以添加课程，不过最多只能连续刷 3 门课程**；
- 如果你不想使用账号密码登录，也可以在账号密码一栏中随意填写，在开始刷课后会提示你进行**扫码登录**。

## 5. 功能设置

第四项为**功能设置**，根据实际需求自行选择：

- 前两项功能已经开发完毕；
- 最后一项还在开发中。

### 5.1 章节测验

第一个是“章节测验”，也就是章节中的测试题。点击下拉框有三个选择，根据自己的实际需求自行选择。

::: warning 注意
“随机答题”请谨慎选择，只有在章节测验**不计入总成绩**的情况下才能使用，否则成绩会很低。
:::

如果你没有选择“不刷题”，则会弹出一个答完题后的设置，根据实际需求自行选择。

### 5.2 视频弹题

第二个是视频中间弹出的题目的作答方式，也有两个选择，根据实际需求自行选择。

### 5.3 讨论部分

第三个是讨论部分的完成方式，同样也有两个选择，根据实际需求自行选择。

### 5.4 倍数设置

第四个是“倍数设置”，**建议设置为 2 倍速**，否则倍速过高，有可能会导致学习通已完成的任务点被清空。

### 5.5 跳过人脸

若课程需要刷脸才能进入，可开启此功能。开启后，第一次刷课需用手机扫码进行人脸验证，之后刷课就会自动跳过。

### 5.6 多端学习

开启后可同时刷多门课程，但**请谨慎开启**。

::: danger 风险提示
开启后有可能清空课程进度，甚至直接挂科。如果不是实在刷不完，还请老老实实一科一科地刷，**一切后果自负**。
:::

### 5.7 秒过视频

只有在视频**可以拖动进度条**的情况下生效。

### 5.8 防锁屏

开启后在刷课的途中鼠标会左右跳动，防止电脑息屏影响刷课。当然，你也可以自行在电脑系统设置中关闭息屏功能。

### 5.9 定时刷课

开启后在不关闭脚本窗口的情况下，可以根据你设定的时间，定时开始刷课或者结束刷课。

::: warning 注意
开启后脚本窗口**一定不能关闭**，否则无法正常定时刷课。
:::

## 6. 关于自动完成作业功能

### 6.1 AI 答题

选择该功能后，将**强制使用 DeepSeek AI** 作为作业的答题方式，并自动保存答案。

::: tip 使用前提
需要先在设置中配置好 **DeepSeek API 密钥**，否则无法正常答题。
:::

### 6.2 选择作业

关于“选择作业”，也有两个选择：

- **手动选择**：进入到作业页面后，你需要手动点击要刷的作业，刷完该作业后程序会自动结束；
- **自动选择**：则默认从第 1 个作业开始，依次刷至最后一个。

## 7. 保存设置

填写完信息后**务必点击“保存”**，否则无法刷课。同样，修改任何信息都要进行保存，否则修改无效。

## 8. 开始刷课

保存好信息后返回“主页”，点击“开始刷课”，脚本会自动打开浏览器登录你的学习通，进行自动刷课。

你也可以选择**定时刷课**，程序会自动按照你设定的时间开始或结束刷课。开启定时刷课后脚本的窗口不能关闭，否则无法定时开启刷课。
