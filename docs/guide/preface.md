## 为什么会有这个脚本

我是一名普通大学生，出于对 Python 的热爱，加上烦人的网课，才制作出该刷课脚本。

这个脚本并非为了逃避学习，而是希望利用技术手段，将我从繁琐的刷课流程中解放出来，把更多精力投入到真正有价值的学习和思考中。

技术是一把双刃剑。使用该脚本需要遵守学校相关规定，并合理规划学习时间，**切勿本末倒置**。
:::
