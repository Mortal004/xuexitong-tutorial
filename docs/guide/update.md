关于更新，可以通过以下渠道获取最新版本：

## 1. GitHub Releases

开源仓库的正式发布页，可以查看每个版本的历史记录。

```text
https://github.com/Mortal004/Xuexitong_shuake/releases/
```

## 2. 夸克网盘

国内访问速度较快，适合大多数同学。

```text
https://pan.quark.cn/s/8ff80d48d6c1
```

## 3. 迅雷网盘

备用下载渠道。

```text
https://pan.xunlei.com/s/VP5_9N46J5V-tJUBCXXpVEaLA1?pwd=9egr#
```

## 4. 脚本内检查更新

也可以直接在脚本的窗口主页点击**检查更新**，如果有新版本，会提示你前往网盘下载最新版本。

::: tip 更新建议
更新前建议先备份当前的设置文件，避免重新填写所有配置。
:::
